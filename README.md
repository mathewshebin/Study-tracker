# 📚 Study Tracker

A personal daily study and food tracker built for exam preparation (April – June).

## Features
- ✅ Full daily schedule with exact timings
- 🍽️ Food plan tracker
- 🔥 Streak counter
- 📅 Separate Mon–Sat and Sunday (Job Day) schedules
- 💾 Data saved locally on your device

## Live App
👉 [Open Tracker](https://mathewshebin.github.io/study-tracker)

## Goal
Clear maximum exams using structured study, revision, and controlled routine.

> Consistency is more important than intensity.
